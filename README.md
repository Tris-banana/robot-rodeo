# Robot Rodeo Custom Code
## What is Robot Rodeo
Robot Rodeo is a hackathon-style competition that took place during the Calgary Stampede.
They gave us 3 days to plan and build a robot for a brand-new game that they released at the start of the competition.
At the end of the three days, every team competed in an elimination bracket to determine the tournament champions.

## The game
This year's game was about collecting hay bales and depositing them in trailers and hoppers. 
We created a catapult robot to shoot the hay bales into the top of the hoppers, and we made it to the semi-finals.
---
This repository contains the code that I created during this competition to control our catapult robot.
